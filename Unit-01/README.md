# Unit 01 – Introduction to Cloud Fundamentals and Services

## Overview
This unit introduced the fundamental concepts of cloud computing, including cloud service models (IaaS, PaaS and SaaS), deployment models, cloud characteristics, virtualisation, automation and the shared responsibility model.

## Learning Activities
- Completed the Unit 1 LectureCast.
- Studied the required reading, including the NIST Definition of Cloud Computing (SP 800-145) and selected chapters from *The Cloud Computing Journey*.
- Participated in the formative discussion comparing AWS and Google Cloud.
- Prepared seminar notes.
- Wrote a personal reflection on the week's learning.

## Skills Developed
- Understanding of cloud computing fundamentals.
- Comparison of major cloud providers.
- Knowledge of cloud service and deployment models.
- Awareness of cloud benefits and challenges.
- Improved academic research and technical writing skills.
