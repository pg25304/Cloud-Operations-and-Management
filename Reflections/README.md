# Learning Reflections — Evidence Index

**M9: Cloud Operations and Management | MSc Cybersecurity | University of Essex Online | October 2026**

## Purpose

This index records five reflections prepared during the module. Together they document the development of cloud knowledge, practical skills, collaboration and professional judgement. They are *individual learning reflections*, not a claim that a reflection was produced every week or for every unit.

> **Access and attribution:** The original Word documents are preserved unchanged in the student's private university OneDrive workspace. The GitHub repository contains this navigation index, not the full reflections or their embedded evidence. Restricted, view-only access to the originals can be provided to the tutor through the assessed e-Portfolio. Any public release of the original documents should first be checked for university material, personal information and assessment requirements.
